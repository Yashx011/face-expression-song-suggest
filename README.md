# Face Expression Song Suggest

A full-stack web application that suggests songs based on detected facial expressions.

## Project Structure

```
face-expression-song-suggest/
├── Backend/      # Express.js backend server
├── frontend/     # React + Vite frontend application
├── .gitignore
└── README.md
```

## Getting Started

### Backend Setup
1. Navigate to the `Backend` folder:
   ```bash
   cd Backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   npm run dev
   ```

### Frontend Setup
1. Navigate to the `frontend` folder:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development app:
   ```bash
   npm run dev
   ```
